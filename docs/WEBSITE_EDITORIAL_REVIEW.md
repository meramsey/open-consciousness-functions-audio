# Website editorial review

## What changed

- Replaced the audio-only landing-page experience with clear Start Here,
  Listening Guide, Functions, Quick Reference, Related Functions, Downloads,
  and About paths while retaining direct access to the verified audio library.
- Added short introduction copy and separately labeled instruction, lifecycle,
  safety, audio, and relationship sections. Added purposeful headings, section
  navigation, breadcrumb links, and prominent cue styling.
- Added optional beginner exploration descriptions for Relax, Focus, and Think
  Fast. The wording explicitly states that these are independent practices and
  not a mandatory progression.
- Added general stereo/device guidance and Android, iOS/iPadOS, Windows, macOS,
  and Linux setup pages with dated vendor references and maintenance caveats.
- Added transcript controls whose text is loaded only from the matching
  published edition's TXT release companion. VTT captions are optional and use
  the corresponding VTT companion.

## What was intentionally preserved

- Function title, description, cue, procedure, lifecycle, safety and approved
  relationship text is projected from the canonical OCF locale export. The site
  does not paraphrase those instructions or infer missing procedures.
- Display cues and spoken cues remain separate. Historical aliases are visibly
  labeled historical/inactive and are never promoted as current commands.
- Draft tags/common-use metadata remains labeled as draft discovery metadata;
  draft procedure text and relationship proposals are not emitted.
- Canonical narration, source/working transcripts, private reference material,
  source evidence paths, and unreleased text are not part of the website export.
- Transcript wording remains exact to its published release edition; the site
  never substitutes current canonical narration for an older recording.
- Existing published MP3, FLAC, artwork, manifest, transcript, collection,
  checksum, URL, tag, and historical-release bytes/identities are unchanged.
- No treatment, guaranteed-state, cumulative biological, or listening-efficacy
  claims were added. Device controls are recommendations, not promises that the
  browser disables system or headphone processing.
