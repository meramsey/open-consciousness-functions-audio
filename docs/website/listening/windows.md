# Windows audio settings

**Verified against linked Microsoft documentation: 2026-11-11.** Labels vary
by Windows version and audio driver. These steps cannot detect every driver,
headphone, or application effect.

## Baseline

- Stereo headphones or stereo earbuds with separate left/right playback are
  required for the intended binaural/channel-separated audio. Speakers, mono
  mixing, or a single earpiece are not equivalent delivery of that audio. If you
  cannot use this setup, use the written guide or an edition-matched transcript
  if available, or skip the audio; no equivalent effects are promised.
- Keep the left/right balance centered unless you use an accessibility
  adjustment.
- Start at a comfortable, clearly audible level and use normal playback speed
  (1.0x). Turn off unwanted repeat, shuffle, crossfade, and optional EQ/effects.
- Do not raise volume to chase a perceived effect.

## Spatial sound and enhancements

1. Open **Settings → System → Sound**.
2. Select the headphone output device.
3. Set **Spatial sound** to **Off** if available. Windows Sonic for Headphones,
   Dolby Atmos for Headphones, and DTS headphone processing are spatial options.
4. Turn **Audio enhancements** off when the device exposes that setting and you
   do not rely on it.

Microsoft's [Windows spatial sound instructions](https://support.microsoft.com/en-us/windows/hardware/drivers/how-to-turn-on-spatial-sound-in-windows)
describe the device properties path; the controls may be under **More sound
settings** on some systems.

## Mono audio and accessibility

Review **Settings → Accessibility → Audio → Mono audio** and channel balance.
Mono mixes the left/right channels and is not equivalent delivery of the
intended binaural/channel-separated audio. Do not disable an accessibility
setting you need. Use the written guide or an edition-matched transcript if
available, or skip the audio; no equivalent effects are promised.

## Player settings and troubleshooting

Check the player's speed, repeat, shuffle, crossfade, normalization, EQ, and
enhancements. If sound seems mono, verify the output device and balance before
changing volume. For current output-device troubleshooting steps, see
[Microsoft's Windows sound and audio guide](https://support.microsoft.com/en-us/windows/hardware/audio/fix-sound-or-audio-problems-in-windows).
Do not increase volume beyond a comfortable level.
