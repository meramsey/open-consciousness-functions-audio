# Repository instructions

- Keep OCF source and audio distribution repositories separate; do not modify the main OCF repository as a side effect.
- Never commit rendered audio, private recordings, voice models, training data, or unapproved artwork. Render success is not publication authorization.
- Preserve stable function and asset identifiers; keep manifests and checksums verifiable and historical release URLs intact.
- Do not overwrite approved releases. Validate changes before committing or publishing.
- Prefer minimal, dependency-light implementations. Report exact error messages when blocked.
